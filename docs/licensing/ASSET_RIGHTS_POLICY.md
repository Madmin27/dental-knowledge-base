# Asset Rights Policy

The normative rights rules are defined in:

`docs/architecture/DENTAL_KNOWLEDGE_BASE_ARCHITECTURE_v0.1.md`

Summary:
- Prefer CC0/public-domain and CC BY 4.0.
- CC BY-SA requires explicit compatibility review.
- CC BY-NC / BY-NC-SA do not enter unrestricted core/public release without separate explicit permission.
- ND cannot be used where modification is required.
- Unknown license blocks publication.
- “Purchased” does not imply web display, derivative, redistribution or download rights.
- Every publishable asset requires a recorded rights decision.
